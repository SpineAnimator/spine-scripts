# SYMBIOTYC Spine Scripts

## Status: legacy source archive only

This repository retains a historical SYMBIOTYC v7.54 ExtendScript source package under `photoshop/` for provenance and license preservation. It is **not an active tool**, is not part of the current Spine Animator architecture, and must not be executed, deployed, or used in production.

The current browser-based tool is [Spine Animator /spine-scripts](https://spineanimator.github.io/spine-scripts/). It uses the independent browser-side `ag-psd` parser and its own source-preservation and fail-closed checks. It does not invoke an external image editor.

No external-editor runtime, ExtendScript dependency, licensed editor runner, or source-execution CI workflow is part of the active SA pipeline.
